# Banla Boutique Hotel Đà Lạt

Website chính thức cho Banla Boutique Hotel — boutique hotel ấm áp, tinh tế tại Đà Lạt.

**“Ngoài lạnh. Trong ấm.”**

## Đặc điểm

- Phong cách boutique ấm áp, tinh tế
- Nội dung tiếng Việt đúng brand voice
- Responsive, tối ưu mobile
- Form đặt phòng trực tiếp
- Sẵn sàng deploy lên GitHub Pages hoặc bất kỳ hosting tĩnh nào

## Cấu trúc

```
/
├── index.html      # Trang chính
├── styles.css      # Style boutique ấm
├── script.js       # Tương tác nhẹ
└── README.md
```

## Chạy local

Mở file `index.html` bằng trình duyệt hoặc dùng live server.

## Deploy GitHub Pages

1. Push repo này lên GitHub
2. Vào Settings → Pages
3. Chọn branch `main` / root
4. Website sẽ live tại `https://<username>.github.io/<repo>`

# Banla Boutique Hotel Đà Lạt

Website chính thức cho **Banla Boutique Hotel** — boutique hotel ấm áp, tinh tế tại Đà Lạt.

> **Ngoài lạnh. Trong ấm.**

## Về dự án

Website được xây dựng với phong cách boutique đúng brand voice của Banla: ấm áp, tinh tế, giàu cảm xúc. Tập trung hoàn toàn vào trải nghiệm của khách sạn này.

## Tính năng

- Thiết kế ấm áp, tinh tế (màu nâu đất, typography Playfair + Inter)
- Responsive đầy đủ (desktop + mobile)
- Menu mobile
- Form đặt phòng trực tiếp
- Nội dung tiếng Việt đúng brand
- Sẵn sàng deploy GitHub Pages

## Cấu trúc

```
/
├── index.html    # Trang chính đầy đủ
├── styles.css    # Design system boutique
├── script.js     # Tương tác (menu, form, scroll)
├── README.md
└── LICENSE
```

## Chạy local

Mở `index.html` bằng trình duyệt hoặc dùng extension Live Server.

## Deploy GitHub Pages

1. Push repo lên GitHub (public)
2. Settings → Pages → Deploy from branch → `main` / root
3. Website live tại `https://<username>.github.io/<repo-name>`
